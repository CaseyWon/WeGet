# WeGet

一个本地运行的微信公众号文章资源解析工具。粘贴文章链接后，可分类预览并下载：

- 文章头图
- 小程序 / 商品卡片图
- 正文图片与视频封面
- 视频、音频与常见附件
- 单项下载或多选 ZIP 打包

## 本地运行

```bash
npm install
npm start
```

打开 <http://localhost:4173>。

## 说明

- 仅接受 `mp.weixin.qq.com` 与 `weixin.qq.com` 文章链接。
- 下载代理使用短期进程内签名，服务重启后需重新解析文章。
- 单个资源限制 50 MB，单次最多打包 100 项。
- 微信可能对高频抓取或部分网络环境进行限制；遇到提示时请稍后重试。
- 请仅下载与使用你拥有相应权利的内容。
